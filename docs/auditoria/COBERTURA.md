# Cobertura de la auditoría Deluxe Eterno

Fecha: 26 de octubre de 2026, America/Lima. Revisión base: `5a0d0439337344b630d797ffc6df0d1a370ebb60`, con cambios locales previos. Documento rector: `D:/JC Estudio/Workspace/output/agente-evaluacion-refactorizacion.md`.

Esta matriz expresa cobertura de revisión, no un porcentaje de cobertura de instrucciones de Java ni una certificación de seguridad. Se leyó el código propio de los grupos indicados; los recursos repetitivos se verificaron mediante su inventario, generador y huella. Las pruebas de ejecución finales usan Java 26 y H2; no se modificó MySQL.

## Inventario de contratos

Públicos: `GET /`, `/nosotros`, `/productos`, `/productos/{id}`, `/servicios`, `/galeria`, `/contacto`, `/login`; `POST /contactos`. El parámetro opcional `categoria` se conserva en catálogo y galería.

Panel: `GET /admin`, `/admin/products`, `/admin/products/new`, `/admin/products/{id}/edit`, `/admin/categories`, `/admin/categories/new`, `/admin/categories/{id}/edit`, `/admin/inquiries`. Escritura: `POST /admin/products`, `/admin/products/{id}/edit`, `/admin/products/{id}/delete`, nueva `/admin/products/{id}/activate`, `/admin/categories`, `/admin/categories/{id}/edit`, `/admin/categories/{id}/delete`, `/admin/inquiries/{id}/status`.

Spring Security gestiona `POST /login` y `POST /logout`; Spring Boot gestiona `/error` y recursos estáticos. Son 25 rutas propias contando la nueva publicación, además de los contratos del framework. Todos los POST administrativos requieren ADMIN y CSRF.

Almacenes: MySQL para ejecución normal, H2 en memoria para pruebas, archivos locales como recursos. Integraciones: Bootstrap/Icons vía CDN y enlaces de redes sociales; no hay pagos, correo saliente, OAuth2, WebAuthn, API externa de negocio, CORS personalizado, trabajadores ni tareas programadas.

## Exclusiones explícitas

- `.git/`, `target/`, `.m2`, extensiones del IDE y dependencias de terceros: no son código propio. Se consultaron versiones resueltas y se construyó el JAR; no se auditó su código interno.
- Credenciales, consultas reales de MySQL y configuración privada de colaboradores: no leídas ni copiadas. `.vscode/settings.json` se revisó solo como configuración local de runtime y sigue ignorada.
- Capturas, binarios históricos, reportes Word/PPT/PDF y fotos repetidas: no se verificó cada píxel durante esta auditoría. Se revisaron fuentes/generadores e integridad; no se reemitieron entregables académicos.
- Infraestructura de producción, migraciones, TLS, backups remotos y despliegue público: **no aplica** al destino local confirmado. No se desplegó ni se ejecutaron migraciones.
- Escaneo SCA completo, carga concurrente, pruebas de estrés, auditoría WCAG formal y cobertura numérica de código: **no verificable** con las comprobaciones realizadas; no se atribuye éxito por inferencia.
